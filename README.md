# PoleSite

A small host for static websites.

You bring a folder — HTML, CSS, images, whatever — and PoleSite gives it an
address on the web. No servers to set up, no build step, no platform to learn.

The idea is a place for the small things: a portfolio, a project page, a
documentation site, a page for a band, a joke. The kind of site that doesn't
need a framework or a hosting bill.

## Status

Not open yet. The platform is being built; this repository holds the holding
page at [polesite.l.cd](https://polesite.l.cd).

## Planned

- Upload a ZIP or a folder of static files.
- Get an address such as `yourname.polesite.l.cd`.
- Replace it whenever you like; the old version goes away.
- Static files only — nothing runs on a server.
